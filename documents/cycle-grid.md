# Сетка цикла

Билд прохода. Не класс TAB, не шрам, не шоп. XP и таблица уровней — [pumping.md](pumping.md). Личность навсегда — [scars.md](scars.md). Бюджет силы уровня — [usefulness.md](usefulness.md).

Пока каталог навыков пуст, уровень по-прежнему сыпет случайный пак. Скелет уже на F3. Навыки в код не входят, пока здесь нет первой строки каталога.

## Слои

| Слой | Что выбираешь | Живёт |
|---|---|---|
| Шоп | ствол, деплой | раунд |
| **Сетка** | как этот проход играет в раунде | до Relapse |
| Шрамы | кем ты стал | навсегда |

XP цикла слепой к роли: [pumping.md](pumping.md). Сетка не запирает TAB. Узел молчит, если этим раундом не занимаешься. Полоска всё равно капает.

Шрамы не тратят SP и не открывают клетки. Отличник множит XP, не число гнёзд.

## Скелет

Потолок графа, не число готовых навыков.

```
8 деревьев × 15 слотов = 120 гнёзд
```

Ядро в центре — вход, без навыка, на уровне 1 уже твоё. Ворота дерева сидят рядом с ядром, без длинной спицы. Чужая рука не на пути: чтобы взять Медицину, Строительство проходить не надо.

Дерево:

```
ворота (слот 0)
  → ветки своего куста до 15
```

15-й слот — место под поздний навык, не дыра. Слот без навыка **купить нельзя**. Новый навык садится в свободное гнездо своего дерева. Граф не перекладываем.

Макет: восемь кустов на целочисленной решётке вокруг ядра. Ветки живые, ребро только к родителю. Не паутина на 150 клеток ZS и не налог пути через мусор.

## SP

```
SP_cycle = max(0, L − 1)
SP_remort = R
SP = SP_cycle + SP_remort
```

`L` — уровень цикла, 1…30. На 30: **29** с прохода. `R` — сколько Relapse уже сделал. Каждый Relapse: **+1 SP** в каждый следующий цикл, навсегда.

На L1 после десятого Relapse уже 10 SP — ворота можно открыть до первой карты.

Один навык = **1 SP**. Стоимостей 2–5 нет: иначе копят на ульту. Замок дерева, когда появится, дороже **позицией** (нужны соседи), не ценой.

Банк нерастраченного — не больше **3**. Пропустил окно аппа — очки не сгорают до трёх. Дальше уровень всё равно приходит, трата ждёт.

Респека среди прохода нет. Relapse стирает взятые клетки. `R` и бонус SP остаются.

На L30 без ремортов 29 из 120 — четверть скелета, не «взял всё». Полный захват при 30 уровне: `R = 91`. Дальше SP некуда, пока скелет 15×8.

## Восемь деревьев

Глагол раунда, не роль TAB. Имена не менять.

| id | Имя | Про что | Не это |
|---|---|---|---|
| `vitality` | Живучесть | падение, blood, бинт, кровотечение | MaxHealth (Кряж), срез у сигила (Опорник), бег (Стриж) |
| `supply` | Снабжение | себе и **с своих** деплоев: worth, старт, забор со своего ящика | чужой ящик (Интендант), срез ремантлера (Мусорщик / Токарь), комиссия шопа (Торговец) |
| `mechanics` | Механика | девайсы: турель, дрон, поле, pack деплоя | HP деплоя-шрам (Инженер), гвоздь |
| `medicine` | Медицина | хил, аптека, союзник | класс TAB, шрам-хил из эскиза |
| `ranged` | Дальний бой | reload, смена, контроль, обращение | урон **пули** |
| `melee` | Ближний бой | замах, шаг в удар | множитель Костолома |
| `build` | Строительство | гвоздь, стена, pack кейда | турель, HP деплоя |
| `shadow` | Тень | нежить этого прохода | человеческие клетки «на всякий» |

Запрет на всю сетку, тот же дух что у шрамов: нет `% к урону пули`. Нет скорости бега. Нет полки MaxHealth. Нет среза у сигила.

Два дерева не платят одно и то же. Механика ≠ Строительство. Снабжение ≠ Интендант: здесь забор **тебе** и с **твоего** деплоя, не бонус чужому из твоего ящика.

## Как открыть

1. Ядро есть.
2. Сосед по ребру скелета уже взят, или это ворота дерева (слот 0, ребро к ядру).
3. В слоте стоит навык из каталога.
4. Есть свободный SP.

Взял — работает сразу. Нет «желаемых» и «активных». Нет слотов ношения. Как шрамы в этом: взятое включено. В отличие от шрамов: сгорает на Relapse.

## Relapse

Метры шрамов и клетки сетки сгорают раздельно. Relapse:

- уровень цикла → 1, XP → 0;
- все клетки сетки пусты;
- `R += 1`, в новом проходе `SP_remort = R`;
- лотерея шрамов — [scars.md](scars.md).

Не смешивать: карта шрама не даёт SP, SP не даёт карту.

## UI

F3. Левый блок персонажа (модель, имя, цикл) всегда. Стрелки у заголовка как в шопе: `<` `>` после названия. Правый блок листается. По умолчанию **Сетка**, дальше **Шрамы**.

Сетка — веб как в ZS: целочисленные клетки, ядро, восемь кустов. Камера та же: колёсико — зум, край панели и ЛКМ-drag — панорама. Навыков в гнёздах пока нет — клик не покупает.

Ап уровня, когда каталог появится: доступная граница скелета, один клик.
