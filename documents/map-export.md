# Карта: с оригинала на своё имя

`map.bsp` — готовая карта с паком. Её не переименовывать и не затирать сборкой. `rmap` — новое имя: строчные буквы, цифры, `_`.

Пак с текстурами, небом и светом пропов лежит внутри bsp. VMF хранит только имена материалов. Имя VMF становится именем сборки.

| | |
|---|---|
| Оригинал | `map.bsp`, копия на столе и файл в голосовании |
| VMF | `C:\Users\Egor\Desktop\rmap.vmf` |
| Сборка | `C:\Users\Egor\Desktop\rmap.bsp` и `D:\Relapse\server\garrysmod\maps\rmap.bsp` |
| Игроки | качают файл из папки сервера |

## Шаги

1. Скопировать оригинал `map.bsp` на рабочий стол.
2. Открыть этот файл в BSPSource. Экспортировать как `rmap.vmf` на рабочий стол.
3. Создать на столе копию `map.bsp` с именем `rmap.bsp`. Это ещё оригинальный файл, около того же размера.
4. Положить эту копию в `D:\Relapse\server\garrysmod\maps\rmap.bsp`.
5. Перед каждым Run Map поставить версию пака **1** у `rmap.bsp`, который лежит рядом с VMF. У оригиналов она 0. **Keep embedded files** передаёт `-keepstalezip`: с версией 0 компилятор пишет `ValidateLump: old version for lump 40` и выходит, VMF не читается, RAD только пересвечивает старый bsp. После удачной сборки версия снова становится 0, поэтому перед следующим экспортом шаг повторяют. То же для любой другой карты: правится bsp рядом с её VMF, не файл в голосовании.

```python
import struct
p = r"C:\Users\Egor\Desktop\rmap.bsp"
data = bytearray(open(p, "rb").read())
struct.pack_into("<i", data, 8 + 40 * 16 + 8, 1)
open(p, "wb").write(data)
```

6. Править `rmap.vmf`. Run Map: **BSP**, **VIS**, **RAD** — Normal, **Don't run the game** включён, **Keep embedded files** включён. Сборка перезаписывает `rmap.bsp` на столе и в папке сервера.

В логе должна быть строка `Loading rmap.vmf`.

Размер `rmap.bsp` остаётся около размера оригинала. Файл в разы меньше — пак не вошёл, на сервер его не класть. Запас для повтора — столовый `map.bsp`.

В окне сервера: `changelevel rmap`. Клиент без своего файла получает карту с сервера. Лимит отправки — `net_maxfilesize 64` в `server.cfg`.
