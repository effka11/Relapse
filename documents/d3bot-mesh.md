# D3bot: правка меша

Боты ходят по D3bot-мешу, не по Source `.nav`. Файл: `garrysmod/data/d3bot/navmesh/map/<карта>.txt`.

Генератор кладёт ноду в центр каждой Source-клетки и связывает всех соседей. Перепад выше 58 u → `Jumping=Needed`. Лестницы — верх/низ по центру кисти и одна вертикаль `Path=Ladder`. Дальше только руками. `relapse_d3bot_rebuild` **стирает** ручные правки.

## Команды

Из игровой консоли (не srcds), нужен SteamID владельца:

| Команда | Что делает |
|---|---|
| `relapse_d3bot_viewmesh` | оверлей, без правок |
| `relapse_d3bot_editmesh` | правки + noclip, остаёшься человеком |
| `relapse_d3bot_savemesh` | запись в `data/d3bot/navmesh/map/` |
| `relapse_d3bot_hidemesh` | выключить оверлей |
| `relapse_d3bot_status` | D3botNav / число нод и связей |
| `relapse_d3bot_sethovered <имя> [значение]` | param на то, что под прицелом |
| `relapse_d3bot_setparam <id> <имя> [значение]` | param по id с таблички |

Пустое значение стирает param. После `setparam` / `sethovered` режим **7** клеит тот же param на следующий элемент.

Пересобрать с нуля (карта перезагрузится):

```
lua_openscript autorun/server/relapse_d3bot.lua
relapse_d3bot_rebuild
```

## Оверлей

Красное — ноды и лучи. Оранжевое — то, что под прицелом. Зелёное — выделенное. Табличка с id: `12` нода, `12-34` связь. Радиус выбора шире, чем рисунок: луч берётся, если он ближе к прицелу, чем площадка.

Дальше **~1024 u** меш не рисуется. Подлети, если клетки пропали. Подписи ближе (~640 u), наведённый — всегда. Наведение узкое: смотри на площадку или луч.

Дальность показа: `d3bot_navmeshing_drawdistance 1024`.

## Режимы

Слева список. **R** листает (или снимает выделение). **1–8** сразу в режим. **ЛКМ** делает действие.

| Клавиша | Режим | ЛКМ | ПКМ |
|---|---|---|---|
| 1 | Create Node | нода в точку прицела | — |
| 2 | Link Nodes | первая нода, потом вторая → луч | — |
| 3 | Merge/Split/Extend | слить две ноды | разрезать / продлить площадку по оси взгляда |
| 4 | Reposition | взять, кликнуть новое место | сдвинуть одну ось (смотри вдоль неё) |
| 5 | Resize Area | выбрать | тянуть край площадки |
| 6 | Copy | набрать ноды | вставить со сдвигом по оси |
| 7 | Set/Unset param | наклеить последний param | стереть этот param |
| 8 | Delete | удалить ноду или луч | снять Area у ноды |

Без `relapse_d3bot_savemesh` рестарт карты откатит правки.

## Пандус

Разрыв — нет луча между соседними клетками.

1. Режим **2**.
2. Клик по нижней клетке, клик по верхней. Луч по полу, не сквозь стену.
3. Лишний воздух — режим **8**, клик по лучу.

На скат **не** ставь `Jumping=Needed`: бот будет прыгать вместо ходьбы.

## Лестница

D3bot хватает кисть, только если идёт по связи с `Path=Ladder` **внутри** `info_ladder`, не по кромке ямы.

1. Режим **8** — лучи через воздух рядом с шахтой.
2. Режим **1** — нода на полу у входа (**A**).
3. Режим **1** — нода **в объёме** лестницы, чуть выше пола (**B**).
4. Режим **1** — нода в объёме у верха (**C**).
5. Режим **1** — нода на верхней площадке (**D**).
6. Режим **2** — A–B, B–C, C–D.
7. На луч **B–C** (лучше и A–B, C–D): смотри на луч, `relapse_d3bot_sethovered Path Ladder`.
8. На C: `relapse_d3bot_sethovered Climbing Needed`.
9. На B и C: `relapse_d3bot_sethovered AimTo Straight`.
10. Режим **4**, если нода в стене или в дыре — подвинь в кисть / на пол.

Промежуточный этаж — ещё одна пара «пол → объём» с `Path=Ladder`, вертикаль между объёмами.

## Частые param

| Где | Имя | Значение | Зачем |
|---|---|---|---|
| связь | `Path` | `Ladder` | бот лезет, Source даёт `MOVETYPE_LADDER` |
| нода | `Climbing` | `Needed` | цель на стене/лестнице |
| нода | `AimTo` | `Straight` | смотрит вдоль лестницы, не на игрока |
| связь | `Jumping` | `Needed` | прыжок вверх (ступени, не скат) |
| нода | `JumpTo` | `Close` / `Always` | прыжок у этой ноды |
| нода | `DuckTo` | `Close` / `Always` | присед |
| нода | `See` | `Disabled` | бот не «видит» цель отсюда |
| связь | `Direction` | `Forward` / `Backward` | односторонняя связь |
