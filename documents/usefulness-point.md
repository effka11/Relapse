# Поинт, XP и U

Один контур: урон → поинты → покупка и XP → уровни.

## Закон

```
1 поинт арсенала = 1 XP
```

Выдача поинтов с урона не меняется. Обычный зомби: `Points = Health / 45` → **225 HP = 5 поинтов**. Любой урон:

```
поинты = урон / MaxHealth × Points
```

Для гуманоида это просто **45 HP урона = 1 поинт = 1 XP**. Добивание: **+1 поинт** последнему удару. Ассист этот плюс не получает. Класс с `Points = 0` (ворона) — без бонуса. `GM.ZombieFinishPoints`.

Зомби поинтов не имеют: урон и киллы идут в XP цикла напрямую (`AddZSXP`), в арсенал не капают.

Worth — другой кошелёк (старт раунда), та же единица: **1 worth = 1 поинт**.

## U одного поинта

Считаем от модели, не от «хотелок». Эталон покупки — T1 арсенал, без налога старших тиров (там цена растёт быстрее U).

```
U_point = U(Battleaxe) / 15
```

Battleaxe в модели = **414.106 U**, цена **15**. Значит:

```
1 поинт = 27.607 U
```

Код: `GM:GetPointUsefulness()`. Цена T1: `GM.Usefulness.ShopT1Price`. Worth того же ствола — те же 15 (`GM.Usefulness.WorthT1Price` = та же полка). `U_worth = U_point`.

Ванильный T3 Shredder ~448 U за 70 поинтов → 6.4 U/поинт. Relapse T5 SCAR ~455 U за **175** → ~2.6 U/поинт. Дороже за тот же U: налог тира, не ломаем `U_point`. Канон всегда T1.

Полки U по тирам — в [usefulness-model.md](usefulness-model.md). T5 ~545 U ≈ 20 справедливых поинтов; шоп берёт налог ниже.

## Налог тира (шоп)

Фарм быстрее справедливых 15. `45 HP = 1 поинт` не режем: на нём XP и `U_point`. Дорожает только полка старше T1.

Одна цена на тир. M19 и MP5 оба **45**, хотя U разный. Скип в T5 — норма: платишь **175**, не 45+75+115+175.

| Тир | Шоп | Справедливо | Налог | Соло 225 HP |
|---|---:|---:|---:|---:|
| T1 | **15** | 13–15 | ×1 | ~2.5 |
| T2 | **45** | 14–16 | ×3 | ~8 |
| T3 | **75** | ~16 | ×5 | ~13 |
| T4 | **115** | 15–16 | ×7.5 | ~19 |
| T5 | **175** | 16–16.5 | ×11.5 | ~29 |

Шаги **+30 / +30 / +40 / +60**. Поздний тир дороже входа.

**175**, не 200: чужие ~200 — ствол уже с обвесом. Relapse: голый ствол + гильза (пачка 7.62×51 = **12** за **15**) + будущий аттач/ремантлер. Не закладывать TCO в `AddPointShopItem`.

Не из этой полки: патроны (всегда **15**, штуки из `$`), worth T1 (**15**), `ScrapVals`, урон за пулю. `LockItemTiers` выключен — волна не дублирует цену.

## Якорь смены (~1000 XP)

Платим **личный объём работы**, не долю пула сервера. Онлайн 8 или 80 не множит ставки. Гейты: ДПС, патроны хила (150 старт + 23 / 60 с), гвозди, пока есть кого бить.

Люди — поинт = XP:

| Действие | 1 поинт | Код |
|---|---|---|
| Урон по зомби-гуманоиду | 45 HP | `HumanoidZombiePointRatio` |
| Добивание зомби | +1 | `ZombieFinishPoints` |
| Хил чужого | 1 HP | `MedkitPointsPerHealth` |
| Ремонт баррикады | 10 HP | `RepairPointsPerHealth` |
| Урон по **твоим** баррикадам | 20 HP | `CadeOwnerPointsPerHealth` |
| Гвоздь | 0 | — |
| Волна (выжил) | 5 + 1/волна | `EndWavePointsBonus` |

Кейдер: доля по живым гвоздям (3 из 4 → 75%). Aegis — владелец доски. Стоять рядом не нужно. Пустая стена без удара не платит. Чинить чужие стены — только ремонт. Свои стены и сам чинит: владелец + ремонт (две работы, ~1500).

Зомби — только XP, без поинтов:

| Действие | 1 XP | Код |
|---|---|---|
| Урон по людям | 5 HP | `ZombieHumanXPPerHealth` |
| Урон по баррикаде | 20 HP | `ZombieBarricadeXPPerHealth` |
| Убийство человека (последний удар) | 100 | `ZombieKillXP` |

Баррикада — один HP на обе стороны: зомби нанёс 20 → 1 XP ему, 1 поинт кейдеру. XP зомби по баррикаде только если рядом человек (`HumanNearby`), как старый счёт урона по кейде. По людям — за фактический HP (без оверкилла).

Не в `U_point` (не арсенал):

| Действие | XP |
|---|---:|
| Победа людей | 300 |
| Победа исходного зомби (люди проиграли) | 300 |
| Килл человека за зомби | 100 |

Исходный зомби = стал зомби до 1-й волны (подготовка). Заражённый в раунде при победе нежити проигрывает.

Типичная занятая смена без победы:

| | Объём | XP |
|---|---|---:|
| Стрелок | ~35k HP зомби + добивания | ~830 |
| Медик | ~750 HP хила | ~750–900 |
| Ремонт чужих стен | ~10k HP | ~1000 |
| Кейд, ушёл стрелять | ~10k по его стенам + пушка | ~1100 |
| Зомби типичный | 600 HP людям / 12k баррикада / 2 килла | ~920 |
| Зомби рашер | 1500 / 3k / 4 килла | ~850 |
| Зомби ломатель | 200 / 18k / 1 килл | ~1040 |

## Замыкание на уровни

Цикл даёт **580 U** за **20325 XP**. Раз 1 XP = 1 поинт:

```
1 XP → 27.607 U в магазин этой карты
1 XP → 580 / 20325 ≈ 0.029 U в постоянный цикл
```

Магазин на ту же единицу сильно жирнее цикла. Так и должно: пушка решает карту, уровень — тонкий плюс навсегда.

Якорь: **20325 / 1000 ≈ 20 карт** до Relapse. См. [pumping.md](pumping.md).

Поздний уровень 20 U ≈ 1/21 Battleaxe. По XP: 1411 поинтов на шаг 29 → 30 ≈ полторы средних карты.

Первый ап (276 XP) — меньше одной средней карты.

Победа: **300 XP**, не поинт. Люди — если выжила команда. Зомби — только исходная зараза (стали зомби во время подготовки, до 1-й волны); заражённые в процессе карты при победе нежити проигрывают. В `U_point` не входит.

Убийство человека за зомби: **100 XP**, не поинт. Последний удар. В `U_point` не входит.

## Зафиксировано

- 1 поинт = 1 XP.
- `U_point = U(Battleaxe) / 15 ≈ 27.607`.
- 45 HP гуманоида = 1 поинт (`HumanoidZombiePointRatio`).
- Добивание: +1 поинт последнему удару (`ZombieFinishPoints`).
- Хил чужого: 1 HP = 1 поинт (`MedkitPointsPerHealth`).
- Ремонт: 10 HP = 1 поинт (`RepairPointsPerHealth`).
- Урон по своим баррикадам: 20 HP = 1 поинт (`CadeOwnerPointsPerHealth`), доля по гвоздям.
- Зомби без поинтов. Урон людям: 5 HP = 1 XP. Баррикада: 20 HP = 1 XP.
- Убийство человека за зомби: 100 XP (`ZombieKillXP`).
- Цикл: 20325 XP, 580 U, ~0.029 U за XP.
- Якорь: 1000 XP / карта, ~20 карт до 30. Личный объём, не пул онлайна.
- Победа: 300 XP (`WinXP`). Исходные зомби выигрывают вместе с нежитью, заражённые в раунде — нет.
- 1 worth = 1 поинт. `U_worth = U_point ≈ 27.607`.
- Шоп дальнего: T1 **15**, T2 **45**, T3 **75**, T4 **115**, T5 **175**. Одна полка на тир. Не из U. Не 200 на T5 (запас на гильзу и обвес).
- Шоп патронов: **15** по умолчанию. Количество = `round_to_3(round(15 / цена_патрона))`. Ползунок 5–45 шаг 5.
