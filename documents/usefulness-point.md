# Поинт, XP и U

Один контур: урон → поинты → покупка и XP → уровни.

## Закон

```
1 поинт арсенала = 1 XP
```

Выдача поинтов с урона не меняется. Обычный зомби: `Points = Health / 45` → **225 HP = 5 поинтов**. Любой урон:

```
поинты = урон / MaxHealth × Points
```

Для гуманоида это просто **45 HP урона = 1 поинт = 1 XP**. Хилка: 8 HP лечения = 1 поинт. Ремонт: 35 HP = 1 поинт.

Сверх урона: **добивание даёт +1 поинт** тому, кто нанёс последний удар. Ассист не получает этот плюс. Класс с `Points = 0` (ворона) — без бонуса. `GM.ZombieFinishPoints`.

Worth — другая валюта (старт раунда). Не путать с поинтом арсенала.

## U одного поинта

Считаем от модели, не от «хотелок». Эталон покупки — T1 арсенал, без налога старших тиров (там цена растёт быстрее U).

```
U_point = U(Battleaxe) / 15
```

Battleaxe в модели = **414.106 U**, цена **15**. Значит:

```
1 поинт = 27.607 U
```

Код: `GM:GetPointUsefulness()`. Цена T1: `GM.Usefulness.ShopT1Price`.

Worth того же ствола 45 → **9.202 U за 1 worth**. Стартовый слот дороже арсенала примерно втрое: за worth ты ещё платишь за вход в раунд.

T3 Shredder ~470 U за 70 поинтов → 6.7 U/поинт. Дороже за тот же U: налог тира, не ломаем `U_point`. Канон всегда T1.

## Что даёт действие

| Действие | Поинты / XP | U в арсенал (× 27.607) |
|---|---:|---:|
| 45 HP по гуманоиду | 1 | 27.6 |
| Добивание (последний удар) | 1 | 27.6 |
| Соло-килл обычного зомби | 6 | 165.6 |
| Купить Battleaxe | −15 | −414.1 |
| Вылечить 8 HP | 1 | 27.6 |

Два с половиной соло-килла ≈ один T1 ствол. Урон по-прежнему 5 за тушку, +1 только за добивание.

## Замыкание на уровни

Цикл даёт **880 U** за **40028 XP**. Раз 1 XP = 1 поинт:

```
1 XP → 27.607 U в магазин этой карты
1 XP → 880 / 40028 ≈ 0.022 U в постоянный цикл
```

Магазин на ту же единицу сильно жирнее цикла. Так и должно: пушка решает карту, уровень — тонкий плюс навсегда.

Якорь: **40028 / 40 ≈ 1000 XP с карты**. См. [pumping.md](pumping.md).

Поздний уровень 40 U ≈ 1/10 Battleaxe. По XP: 1662–3321 поинтов ≈ 1.7–3.3 средних карты.

Первый ап (385 XP) — меньше одной средней карты.

Победа: **300 XP**, не поинт. Люди — если выжила команда. Зомби — только исходная зараза (стали зомби во время подготовки, до 1-й волны); заражённые в процессе карты при победе нежити проигрывают. В `U_point` не входит.

Убийство человека за зомби: **100 XP**, не поинт. Последний удар. В `U_point` не входит.

## Зафиксировано

- 1 поинт = 1 XP.
- `U_point = U(Battleaxe) / 15 ≈ 27.607`.
- 45 HP гуманоида = 1 поинт (как сейчас).
- Добивание: +1 поинт последнему удару (`ZombieFinishPoints`).
- Цикл: 40028 XP, 880 U, ~0.022 U за XP.
- Якорь: 1000 XP / карта, 40 карт до 30.
- Победа: 300 XP (`GM.WinXP`), не поинт. Исходные зомби выигрывают вместе с нежитью, заражённые в раунде — нет.
- Убийство человека за зомби: 100 XP (`GM.ZombieKillXP`), не поинт.
- Worth отдельно: ≈ 9.202 U.
