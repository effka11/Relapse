# Шрамы

Плейстайл Relapse. Не класс TAB и не дерево. Каждый шрам — своё имя, свой счётчик, свой эффект. Цикл XP и сетка прохода сюда не входят: [pumping.md](pumping.md), [cycle-grid.md](cycle-grid.md). U — [usefulness.md](usefulness.md).

В пуле сейчас **одиннадцать** обычных шрамов: Наёмник, Торговец, Токарь, Лидер, Интендант, Стриж, Костолом, Опорник, Инженер, Мусорщик и Кряж. Редкие — отдельно, не в тройке по весу: пока **Отличник**. Ранг **без капа**. Полезность убывает, к нулю не приходит. Остальные имена в этом файле — эскиз, не закон и не код.

После Relapse выпадают **3 карты**, берёшь **одну**: новый I или +1 к уже полученному. Имён больше трёх — вес решает состав, не «всегда топ».

**Слотов нет.** Нет loadout, нет «надеть три из коллекции». Каждый полученный шрам активен сразу и всегда. Три карты — размер лотереи, не размер ношения. Примеры из эскиза в тройку не подмешиваются.

Силу без слотов держат три вещи, не лимит ношения:

- 1 выбор за Relapse — ширина растёт по одному имени за проход.
- Два шрама не платят одно и то же.
- Убывание `n` внутри имени.

## Счётчик

У каждого шрама два числа за **этот цикл** (сгорают на Relapse):

| Поле | Зачем |
|---|---|
| `count` | То, что видит игрок. У Наёмника — добивания. |
| `meter` | Взвешенный объём. Им считается лотерея. |

Сырой `count` в лотерею не идёт: 50 убийств и 750 HP хила — оба «занятая смена», не 50 против 750.

```
affinity = meter / pace
```

`pace` — объём одной занятой смены этой работы. Якорь смены тот же, что у XP: [usefulness-point.md](usefulness-point.md). Одна занятая смена на шрам ≈ **1.0 affinity**. Двадцать карт мейном ≈ 20.

`meter` не равен поинтам, но **темп** с них срисован. Не плодить второй фарм.

## Как не топорно

- Считать работу, не клики. Ворона (`Points = 0`) не кормит Наёмника. (В эскизе: гвоздь спамом не кормит Бригадира, хил в полного не кормит Костоправа.)
- Вес события — из уже принятых ставок, не «1 килл = 1».
- Один выстрел может коснуться нескольких будущих шрамов. Добивание в голову пишет Наёмника. Покупка у чужого ящика пишет Торговца владельцу, не покупателю. Ап в мастерской пишет Токаря тому, кто платит скрап. Поинт на месте 1–3 TAB пишет Лидера сразу, не в конце волны. Чужой забор из твоего ящика снабжения пишет Интенданта владельцу. Смещение на беге пишет Стрижа. Удар ближним по зомби пишет Костолома. Удар по тебе у сигила пишет Опорника. Удар по твоему деплою пишет Инженера. Чужой ап на твоём ремантлере пишет Мусорщика. Удар по тебе пишет Кряжа. Базовый XP (до множителя) пишет Отличника.
- Кит на worth сам по себе счётчик не пишет. Купил аптеку и стрелял — растёт Наёмник. Поставил ящик и никто не купил — Торговец молчит. Разобрал ствол на скрап — Токарь молчит: это приход, не расход. Четвёртый на TAB — Лидер молчит. Поставил ящик снабжения и сам из него берёт — Интендант патроны даёт, метр молчит. Стоит с зажатым Shift — Стриж молчит. Машет в воздух — Костолом молчит. Стоит у сигила без удара — Опорник молчит. Поставил турель и её не бьют — Инженер молчит. Сам апнул на своём станке — Мусорщик молчит. Сидит в спавне — Кряж молчит. XP не капнул — Отличник молчит.

## Убывание ранга

Ранг `n = 1, 2, …`. Три семьи. Не мешать.

Интервал «+1 ресурс каждые x событий»:

```
x(n) = x_∞ + (x_1 − x_∞) / (1 + 0.18 × (n − 1))
```

`x` дробный. Остаток копится. Не округлять до целого: иначе полка из десяти рангов с одним и тем же `x`.

Доля механики с потолком `p_∞` (срез, скорость, DR):

```
p(n) = p_∞ × n / (n + 8)
```

Или пол + хвост: `p = p_0 + p_t × n / (n + 8)`. `n = 1` → 11% хвоста. `n = 8` → 50%. Не для плюса в штуках: I заберёт полку.

**Ступени** — плюс в штуках (HP, пункты процента). Канон:

```
a = 3,  b = 2,  t = 10

δ(1) = δ(2) = a
δ(3) = δ(4) = δ(5) = b
n ≤ 5: add(n) = сумма δ
n ≥ 5: add(n) = 2a + 3b + round(t × (n − 5) / (n + 3))
```

`2a + 3b = 12`. I и II по **+3**. III–V по **+2**. Дальше **+1** и в хвост. ∞ → **22**.

| n | δ | add |
|---:|---:|---:|
| 1 | +3 | 3 |
| 2 | +3 | 6 |
| 3 | +2 | 8 |
| 4 | +2 | 10 |
| 5 | +2 | 12 |
| 6 | +1 | 13 |
| 8 | +1 | 15 |
| 10 | +1 | 16 |
| 20 |  | 19 |
| 50 |  | 20 |
| ∞ |  | 22 |

Новый шрам в штуках — эта таблица, не свой `n/(n+k)`. Единица своя: HP, п.п. XP. `a,b,t` не трогать, пока отдельно не сказано.

## Наёмник

Счётчик: добивания зомби (последний удар). Ассист не пишет.

```
count += 1
meter += (zombie.Points or 0) / 5
```

Обычный гуманоид `Points = 5` → `meter +1`. Босс с большим `Points` тяжелее. Ворона 0.

`pace = 50` — добивания занятой стрелковой смены (~52 финиша при ~830 XP).

Эффект в **этом раунде**:

```
k(n) = 3 + 9 / (1 + 0.18 × (n − 1))
```

Каждые `k(n)` добиваний на этой карте — **+1 поинт**. Остаток живёт до конца карты, на changelevel сбрасывается.

| n | k | Поинты с 50 добиваний |
|---:|---:|---:|
| 1 | 12.00 | 4.2 |
| 2 | 10.63 | 4.7 |
| 5 | 8.23 | 6.1 |
| 10 | 6.44 | 7.8 |
| 20 | 5.04 | 9.9 |
| 50 | 3.92 | 12.8 |
| ∞ | 3.00 | 16.7 |

I → II заметно. XX → XXI почти нет, но плюс есть. Потолок ≈ бесплатный T1 за занятую карту, не T5.

## Торговец

Счётчик: чужие покупки в **твоём** арсенальном ящике. Свои покупки, worth и ремантлер не пишут.

```
count += 1
meter += cost
```

`cost` — сколько поинтов заплатил другой игрок. T1 за 15 и T5 за 175 оба «одна покупка» в `count`; в лотерею идёт сумма чека.

`pace = 250` — чужой оборот занятой смены у ящика (несколько T2 и патронов, не весь сервер).

Базовая маржа ящика — **4%** (`ArsenalCrateCommission`). Шрам не заводит второй кошелёк: поднимает этот процент.

```
cut(n) = 0.04 + 0.08 × n / (n + 8)
владелец получает cost × cut(n)
```

`p(n) = 8% × n/(n+8)` — добавка в процентных пунктах, не множитель «ещё раз от уже поднятого». I → +0.89 п.п. ∞ → +8 п.п. Потолок среза **12%**, не половина чека.

| n | p | срез | лишние поинты с 250 оборота |
|---:|---:|---:|---:|
| 1 | 0.89% | 4.89% | 2.2 |
| 2 | 1.60% | 5.60% | 4.0 |
| 5 | 3.08% | 7.08% | 7.7 |
| 8 | 4.00% | 8.00% | 10.0 |
| 10 | 4.44% | 8.44% | 11.1 |
| 20 | 5.71% | 9.71% | 14.3 |
| 50 | 6.90% | 10.90% | 17.2 |
| ∞ | 8.00% | 12.00% | 20.0 |

250 оборота без шрама — 10 поинтов комиссии. I слабее Наёмника на стрелковой смене: ящик ждёт чужой чек. Занятый ящик на 500 оборота догоняет Наёмника I. ∞ ≈ +20 с 250 — тот же порядок, что Наёмник ∞ с 50 добиваний, не T5.

## Токарь

Счётчик: расход скрапа в **мастерской** (ремантлер). Ап качества ствола и покупка за скрап с ремантлера. Разбор на скрап, ящик поинтов и worth не пишут.

```
count += 1
meter += cost
```

`cost` — прайс в скрапе **до** скидки. Мелкий ап и дорогой оба «одна операция» в `count`; в лотерею идёт сумма счёта. Скидка affinity не раздувает.

`pace = 50` — скрап занятой смены у станка (пара апгрейдов T2–T3, не разбор всей каретки).

Шрам не даёт скрап и не трогает комиссию владельца станка. Платишь меньше со своего кошелька.

```
p(n) = 0.20 × n / (n + 8)
pay = max(1, ceil(cost × (1 − p(n))))
```

I → −2.2%. ∞ → −20%. Не половина счёта. `ceil`, чтобы мелочь не становилась бесплатной: T1 за 6 скрапа на I всё ещё 6.

| n | p | платишь | экономия с 50 скрапа |
|---:|---:|---:|---:|
| 1 | 2.22% | 97.8% | 1.1 |
| 2 | 4.00% | 96.0% | 2.0 |
| 5 | 7.69% | 92.3% | 3.8 |
| 8 | 10.00% | 90.0% | 5.0 |
| 10 | 11.11% | 88.9% | 5.6 |
| 20 | 14.29% | 85.7% | 7.1 |
| 50 | 17.24% | 82.8% | 8.6 |
| ∞ | 20.00% | 80.0% | 10.0 |

1 скрап ≈ 2.2 поинта (`PointsToScrap`). I с 50 ≈ +2.4 поинта в экономии — рядом с Торговцем I. ∞ ≈ 10 скрапа ≈ 22 поинта, тот же порядок, что Торговец ∞ с 250 оборота, не T5.

Чужой станок тоже считается: пишет тот, кто платит, не хозяин. Хозяин без своих апгрейдов Токаря не качает.

## Лидер

Счётчик: поинты, начисленные **пока** ты на месте **1–3** TAB (`Frags` среди людей). Место смотрится в момент `AddPoints`, до этого начисления. Упал на 4-е — следующий поинт уже без множителя. 4-е и ниже, труп, зомби, worth не пишут.

```
gained — поинты до множителя, не nomul
count += gained
meter += gained × s(r)
s(1) = 1
s(2) = 2/3
s(3) = 1/3
```

`r` — место по текущим `Frags`, ничья → меньший UserID выше. Меньше трёх людей — есть только те места, что есть. Соло всегда 1-е.

`pace = 830` — занятая стрелковая смена на 1-м. Третий с теми же 830 — треть смены в лотерее, не «как первый».

Множитель на этот же `AddPoints`, сразу. Не пакет в конце волны. Урон, хил, ремонт, добивание. Бонус волны и комиссия ящика (`nomul`) не трогает. 4-е место — множитель 0, шрам спит.

```
p(n) = 0.08 × n / (n + 8)
mul(r, n) = p(n) × s(r)
pay = gained × (1 + mul)
```

I на 1-м → +0.89%. ∞ на 1-м → +8%. Не десятки процентов skillweb. 2-е и 3-е — те же 2/3 и 1/3.

| n | p (1-е) | 2-е | 3-е | лишние с 830 на 1-м |
|---:|---:|---:|---:|---:|
| 1 | 0.89% | 0.59% | 0.30% | 7.4 |
| 2 | 1.60% | 1.07% | 0.53% | 13.3 |
| 5 | 3.08% | 2.05% | 1.03% | 25.5 |
| 8 | 4.00% | 2.67% | 1.33% | 33.2 |
| 10 | 4.44% | 2.96% | 1.48% | 36.9 |
| 20 | 5.71% | 3.81% | 1.90% | 47.4 |
| 50 | 6.90% | 4.60% | 2.30% | 57.2 |
| ∞ | 8.00% | 5.33% | 2.67% | 66.4 |

830 — занятая стрелковая смена в поинтах. Место одно на сервер: I на 1-м ≈ половина T1, толще Наёмника I. ∞ на 1-м ≈ T2, не T5. 3-е на I ≈ 2.5 с той же смены — подиум есть, лидерства нет.

Наёмник платит добивание. Лидер платит место. Стоять первым без работы множитель не кормит: `mul` от нуля — ноль.

## Интендант

Счётчик: чужие заборы из **твоего** ящика снабжения (`prop_resupplybox`). Свой забор, worth, арсенал и ремантлер не пишут.

```
count += 1
meter += 1
```

Одно взятие — один кулдаун, калибр в лотерею не идёт. `pace = 15` — чужие выдачи занятой смены у ящика (несколько людей, не весь сервер).

Бонус патронов — с **ящика**, ранг владельца. Берут все, кто открыл этот ящик, **включая владельца**. Чужой интендант не бафает твой ящик. Карта `item_ammo_crate` и пачка из шопа — нет.

```
amount = AmmoCache[тип]   -- у Relapse это ShopCount (round_to_3(round(15 / цена_патрона)))
p(n) = 0.25 × n / (n + 8)
bonus = ceil(amount × p(n))
give = amount + bonus
```

I → +1 к 3–24 патронам. ∞ → +25%, на 24 (9×19) это +6, на 18 (7.62×39) это +5, не второй ящик (это Stockpile). `ceil`, чтобы I было видно.

| n | p | + к 24 (9×19) | + к 18 (7.62×39) |
|---:|---:|---:|---:|
| 1 | 2.78% | 1 | 1 |
| 2 | 5.00% | 2 | 1 |
| 5 | 9.62% | 3 | 2 |
| 8 | 12.5% | 3 | 3 |
| 10 | 13.9% | 4 | 3 |
| 20 | 17.9% | 5 | 4 |
| 50 | 21.6% | 6 | 4 |
| ∞ | 25.0% | 6 | 5 |

Комиссия 0.15 поинта с чужого взятия не трогает. Нет владельца — нет бонуса.

## Стриж

Счётчик: дистанция **бега**. `IN_SPEED`, на земле, не присед, не ghost. Шаг, воздух, стена с зажатым Shift не пишут. Человек, не зомби.

```
count += hu
meter += hu
```

`pace = 50000` — занятая смена на ногах (~3.5 мин бега при 240 u/s, ~1.3 км). Не стоять в кейде.

Эффект только на `RunSpeed` (`SetupMove`, Shift). `WalkSpeed` 95, присед, ghost, лестница не трогает. Вес ствола сидит в беге — множитель поверх итогового бега. Шаг почти не трогает.

Чистый `n/(n+8)` на маленьком потолке даёт I +2 u: воздух. Пол, чтобы I было ходом; потолок, чтобы ∞ не обгонял lacerator (270). Фаст 255.

```
p(n) = 0.03 + 0.07 × n / (n + 8)
run = RunSpeed × (1 + Σp)
```

`Σp` — сумма долей: сетка, этот `p(n)`, другие улучшения. Не `× (1 + p_сетка) × (1 + p(n))`.


База бега **240** (~22 км/ч). I → 249. ∞ → 264 (~24 км/ч). Шаг 95.

## Костолом

Счётчик: удары **ближним** по зомби (`IsMelee` / `Relapse.Melee`). Промах, мир, проп, приклад ствола, пуля, ворона (`Points = 0`) не пишут. Человек, не зомби-когти.

```
count += 1
meter += hp
```

`hp` — HP, который снял бы удар **до** множителя, не больше остатка. Бонус affinity не раздувает.

`pace = 3000` — HP ближним занятой смены (~13 тушек 225).

Множитель на урон этого удара по нежити. Не пуля, не турель, не отдельный слой от skillweb. Сетка Сила и этот `p(n)` — одна сумма.

```
p(n) = 0.04 + 0.16 × n / (n + 8)
dmg = MeleeDamage × (1 + Σp)
```

`Σp` — Сила, этот `p(n)`, `MeleeDamageMultiplier`. Не `× (1 + p_сетка) × (1 + p(n))`.

Полки 225 HP: кулаки 15 / 15 ударов, нож 24 / 10, мачете 38 / 6. I снимает удар с ножа. Мачете шесть ударов до самого ∞. ∞: мачете 5, не четырёх.

## Опорник

Счётчик: входящий урон **тебе**, пока ты в **512** hu от незаражённого сигила (тот же круг, что `HumanNearby`). Заражённый, далеко, падение, утопление не пишут. Человек, не зомби. Не аура союзникам и не HP камня.

```
incoming — урон до среза, от нежити
count += incoming
meter += incoming
```

Срез affinity не раздувает. `pace = 200` — HP входящего на занятой точке (волна под ударом, не стоять в тишине).

```
p(n) = 0.05 + 0.15 × n / (n + 8)
taken = incoming × (1 − p(n))
```

Человек 100 HP. Коготь классики **35**: без шрама 3 удара. I → 4. Nightmare **55**: без шрама 2 удара, ∞ → 3. Не половина входящего.

| 2 | 8.00% | 4 | 2 |
| 5 | 10.8% | 4 | 2 |

## Инженер

Счётчик: входящий урон по **твоим** деплоям из `GM.DeployableInfo` (ящик, снабжение, ремантлер, турель, zapper, дрон, камера…). Гвоздь, доска Aegis, проп карты, сигил, чужой деплой не пишут.

```
incoming — урон по объекту до бонуса HP
count += incoming
meter += incoming
```

Бонус max HP affinity не раздувает. `pace = 400` — HP входящего на занятой постройке (один ящик 400 или несколько жизней турели 150). Поставил и не бьют — молчит.

Владелец в момент постановки. Ранг на `MaxObjectHealth`, текущие HP с полным запасом. Не баррикада.

```
p(n) = 0.05 + 0.15 × n / (n + 8)
max = MaxObjectHealth × (1 + p(n))
```

Коготь 35. Ящик 400: 12 ударов → I 13. Турель 150: 5 ударов, ∞ → 6. Не двойной запас.

| n | p | ящик 400 | турель 150 |

| 1 | 6.67% | 13 | 5 |
| 2 | 8.00% | 13 | 5 |
| 5 | 10.8% | 13 | 5 |
| 8 | 12.5% | 13 | 5 |
| 10 | 13.3% | 13 | 5 |
| 20 | 15.7% | 14 | 5 |
| 50 | 17.9% | 14 | 6 |
| ∞ | 20.0% | 14 | 6 |

Искровой в эскизе — реген турели, не этот шрам.

## Мусорщик

Счётчик: чужие **апгрейды** на **твоём** ремантлере. Свой ап, разбор на скрап, ящик поинтов и worth не пишут. Токарь — расход плательщика, не этот шрам.

```
count += 1
meter += scrapcost
```

`scrapcost` — прайс апгрейда **до** скидки Токаря. Базовая комиссия станка — **8%** (`ceil(scrapcost * 0.08)` в бак станка). Шрам поднимает этот процент, скрап по-прежнему в `SetScraps`, не в карман сразу.

`pace = 80` — чужой скрап-оборот занятой смены у станка (несколько T2–T3, не вся каретка сервера).

```
cut(n) = 0.08 + 0.08 × n / (n + 8)
scrap = ceil(scrapcost × cut(n))
```

I → +0.89 п.п. ∞ → +8 п.п. Потолок среза **16%**, не четверть чужого счёта. T2 за 16 на I всё ещё 2 скрапа (`ceil`): видно на T5 за 70.

|---:|---:|---:|---:|---:|
| 1 | 0.89% | 8.89% | 0.7 | 1 |
| 2 | 1.60% | 9.60% | 1.3 | 1 |
| 5 | 3.08% | 11.1% | 2.5 | 2 |
| 8 | 4.00% | 12.0% | 3.2 | 3 |
| 10 | 4.44% | 12.4% | 3.6 | 3 |
| 20 | 5.71% | 13.7% | 4.6 | 4 |
| 50 | 6.90% | 14.9% | 5.5 | 5 |
| ∞ | 8.00% | 16.0% | 6.4 | 6 |

80 без шрама — 6.4 скрапа комиссии. I слабее Торговца I: станок ждёт чужой ап. ∞ ≈ +6 скрапа ≈ 14 поинтов, тот же порядок, что Торговец, не T5.

## Кряж

Счётчик: входящий урон **тебе** от нежити. Падение, утопление, спавн не пишут. Человек, не зомби. Опорник — срез у сигила, не этот шрам. Костоправ в эскизе — хил чужих.

```
incoming — урон до среза Опорника
count += incoming
meter += incoming
```

`pace = 250` — HP входящего на занятой смене под ударом. Макс HP affinity не раздувает.

База человека **100**. Плюс к `MaxHealth`, текущие HP не лечит сам. Не `%`, не blood armor.

Ступени, единица HP: `max = 100 + add(n)`.

II → **+6** (106): три когтя 35 = 105 не хватает. V → **+12** (112): два удара 55 = 110 не хватает. ∞ → **+22** (122). Четыре когтя 35 = 140 — не достаёт.

Тик цикла `hp_1` — другой слой, кап +15. Кряж — полка ударов.

## Отличник

Редкий. В общую тройку по `affinity` **не входит**: XP пишут все, иначе карта всегда в топе.

Счётчик: **базовый** XP цикла, до множителя. Поинты шопа не пишет. Множитель себя не кормит. Человек и зомби — цикл слепой к роли.

```
base — XP, как если бы 1 поинт = 1 XP (зомби: сырой XP)
count += base
meter += base
```

`pace = 1000` — якорь занятой смены. Метр на F3, в вес лотереи обычных не идёт.

Поинты арсенала не трогает. Ломает только связку **1 поинт = 1 XP**: [pumping.md](pumping.md) остаётся базой.

Ступени, единица п.п. XP. Дробный остаток копится.

```
xp = base × (1 + add(n) / 100)
```

I → **+3%**. ∞ → **+22%**. Не ×2. Якорь 1000 XP/карта: 20.3 карты до 30 без шрама, **19.7** на I, **18.1** на V, **16.7** на ∞.

|---:|---:|---:|---:|
| 1 | 3 | 1030 | 19.7 |
| 2 | 6 | 1060 | 19.2 |
| 3 | 8 | 1080 | 18.8 |
| 4 | 10 | 1100 | 18.5 |
| 5 | 12 | 1120 | 18.1 |
| 6 | 13 | 1130 | 18.0 |
| 8 | 15 | 1150 | 17.7 |
| 10 | 16 | 1160 | 17.5 |
| 20 | 19 | 1190 | 17.1 |
| 50 | 20 | 1200 | 16.9 |
| ∞ | 22 | 1220 | 16.7 |

Лидер множит поинты, Отличник — XP после. Не одно и то же.

## Лотерея

Цикл 30/30, игрок жжёт Relapse. Считаем `affinity` по метрам **этого** цикла. Пул обычных — **каталог без редких**, не эскиз.

В пуле одиннадцать обычных — тройка режется. Relapse даёт три карты из одиннадцати: Наёмник, Торговец, Токарь, Лидер, Интендант, Стриж, Костолом, Опорник, Инженер, Мусорщик, Кряж, I или ап. Берёшь одну. Вес решает состав.

Редкие (`honor` / Отличник) в этот вес **не входят**.

```
w_i = (affinity_i + 0.25) ^ 0.65
```

`+0.25` — пол. Неигранный шрам жив, лидер не 100%. `0.65` сжимает отрыв.

Достаём до 3 карт **без возвращения** (Plackett–Luce) из обычных, но не больше, чем обычных имён в пуле:

1. Нормализовать `w`, взять одну.
2. Если у взятой есть `feed` — остальные с тем же `feed`: `w *= 0.4`.
3. Повторить, пока нет трёх или пул кончился.

Инвариант: предложенные три обычных **не равны** трём максимальным `affinity`. Если выпали ровно топ-3 — третью карту перетянуть из остальных обычных тем же весом. Не «почти всегда топ», а запрет на точный топ. В пуле одиннадцать обычных — перетянуть есть куда.

После инварианта — редкость. Один бросок на Relapse:

```
q_rare = 0.15
```

С шансом 15% **третью** карту заменить на редкий из пула редких (пока только Отличник, равномерно когда их больше). Не четвёртая карта. `feed` обычных не трогает. Инвариант топ-3 на редкого не распространяется.

Карта: «Наёмник I» / … / «Кряж I», или «Отличник I» если редкий сел на третье место, или «I → II», если это имя уже есть.

Пока выбор не сделан, карты лотереи висят на F3. Новый Relapse без выбора копится: 2×, 3×. После взятия, если выборы ещё есть, лотерея перетягивается. Редкий бросок — заново на каждую тройку.

Каталог на F3 показывает все имена, редкие пометкой. Неполученные — серые, карточка всё равно открывает описание справа.

Берёшь одну. Остальные не выдаются. Метры цикла обнуляются.

## Зафиксировано

- В пуле одиннадцать **обычных** шрамов: `mercenary` / Наёмник, `merchant` / Торговец, `turner` / Токарь, `leader` / Лидер, `quartermaster` / Интендант, `swift` / Стриж, `breaker` / Костолом, `anchor` / Опорник, `engineer` / Инженер, `scavenger` / Мусорщик, `bole` / Кряж. Редкий: `honor` / Отличник. Остальные имена в файле — эскиз.
- Шрам уникален. Не класс TAB.
- `affinity = meter / pace`. `pace` — занятая смена. Редкий в `w_i` обычных не входит.
- Ступени: `a=3, b=2, t=10`, `add` как в «Убывание ранга». Плюс в штуках. Не `n/(n+8)`.
- Наёмник: `meter += Points/5`, `pace = 50`, `k(n) = 3 + 9 / (1 + 0.18(n−1))`.
- Торговец: чужой `cost` в твоём ящике, `pace = 250`, срез `4% + 8% × n/(n+8)`. Свои покупки, worth, ремантлер не пишут.
- Токарь: свой `cost` скрапа в мастерской, `pace = 50`, `pay = ceil(cost × (1 − 0.20 × n/(n+8)))`. Разбор на скрап не пишет.
- Лидер: живое место 1–3 TAB в момент `AddPoints`, `meter += gained × s(r)`, `pace = 830`, сразу `pay = gained × (1 + 8% × n/(n+8) × s(r))`. Конец волны не платит. 4-е место не пишет.
- Интендант: чужой забор из твоего ящика снабжения, `pace = 15`, `give = amount + ceil(amount × 0.25 × n/(n+8))`. Бонус всем с этого ящика, в т.ч. себе. Свой забор метр не пишет.
- Стриж: дистанция бега, `pace = 50000` hu, `p(n)` в `Σp` бега (`0.03 + 0.07 × n/(n+8)`). Шаг, присед, ghost, зомби не трогает.
- Костолом: удар ближним по зомби, `pace = 3000` HP, только `MeleeDamage × (1 + 0.04 + 0.16 × n/(n+8))`. Пуля, промах, ворона не пишут. Мачете 6 ударов до ∞.
- Опорник: входящий от нежити в 512 hu от незаражённого сигила, `pace = 200`, `taken = incoming × (1 − (0.05 + 0.15 × n/(n+8)))`. Не аура, не камень. Стоять без удара не пишет.
- Инженер: входящий по твоим деплоям из `DeployableInfo`, `pace = 400`, `max = MaxObjectHealth × (1 + 0.05 + 0.15 × n/(n+8))`. Гвоздь, Aegis, сигил, чужой деплой не пишут.
- Мусорщик: чужой ап на твоём ремантлере, `pace = 80`, срез `8% + 8% × n/(n+8)`. Свой ап и разбор не пишут. Токарь не этот шрам.
- Кряж: входящий от нежити, `pace = 250`, ступени, `max = 100 + add(n)`. Человек. Не лечит сам. Опорник не этот шрам.
- Отличник: редкий, `q_rare = 0.15` на третью карту после инварианта. `meter += base` XP до множителя, `pace = 1000`, ступени, `xp = base × (1 + add(n)/100)`. Поинты не трогает. В `w_i` обычных не входит.
- Ранг бесконечен. Интервал, `n/(n+8)` и ступени не обнуляют плюс.
- В пуле одиннадцать обычных имён: Relapse — три карты, берёшь одну. Инвариант «не топ-3» только среди обычных. Редкий бросок после.
- Пока выбор не сделан, карты висят на F3. Новый Relapse без выбора копится: 2×, 3×.
- Слотов нет. Все полученные шрамы активны.
- Вес `(affinity + 0.25)^0.65`. `feed` ×0.4. Никогда не точные топ-3. Пока не из чего — не применять.
- Метры цикла сгорают. Ранги шрамов нет.
- Урон за пулю в каталоге не живёт.
