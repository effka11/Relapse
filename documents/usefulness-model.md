# Модель U предмета

Цикл тратит U. Предмет стоит U. Один язык, разный масштаб: уровень даёт десятки, оружие — сотни.

Оружие **не округляется** к 10. Считаем точное число. Пак уровня по-прежнему ходит тиками 10 — это размер чипа баффа, не цена пушки.

Код: `GM.Usefulness.Models` в `gamemode/sh_usefulness_model.lua`.

## Зачем Scale = 400

Раньше эталонный пистолет был 40 U — ровно один уровень 21–30. Тогда ап уровня = целое оружие. Это слишком жирно для цикла.

Теперь эталон ≈ 400 U.

| | U | Сколько это |
|---|---:|---|
| Уровень 2–10 | 20 | ~1/20 стартового пистолета |
| Уровень 21–30 | 40 | ~1/10 стартового пистолета |
| Весь цикл | 880 | чуть больше двух стартовых пистолетов |
| Battleaxe | 414.1 | эталон дальнего |
| Crowbar | 400 | эталон ближнего |

Десять поздних уровней ≈ одно стартовое оружие, не одно.

## Как считается — на пальцах

Есть эталон. Для пистолетов это Battleaxe: урон 24, 5 выстрелов в секунду, обойма 12, и так далее. Если бы все статы совпали с эталоном, U было бы ровно **400**.

Любая другая пушка: каждый стат сравниваем с эталоном и получаем **множитель**.

- Урон 48 при эталоне 24 → множитель **2** (вдвое лучше).
- Урон 12 → множитель **0.5** (вдвое хуже).
- Разброс 3.25 при эталоне 1.625 → множитель **0.5** (кучность хуже, для неё меньше = лучше, поэтому эталон делим на стат).

Дальше множитель **не идёт в сумму как есть**. Его возводят в показатель `w` — насколько этот стат важен.

- Урон `w = 0.35`. Вдвое больше урона: `2^0.35 ≈ 1.27`. В U попадёт +27%, не +100%.
- Отдача `w = 0.05`. Вдвое лучше отдача почти не двигает цену: `2^0.05 ≈ 1.035`.

Потом все эти степени **перемножаются** и умножаются на 400.

```
U = 400 × TypeMul × AmmoMul × (множ_урона^0.35) × (множ_темпа^0.15) × …
```

`AmmoMul = (0.30 / $за_патрон) ^ 0.05`. Якорь — 9×18 по $0.30. В Π не входит: сумма `w` по-прежнему 1, эталон без патрона остаётся 400. Дороже патрон — меньше U, слабо (`^0.05`).

Окупаемость — отдельный стат, не множитель U. Пока урон возвращает U боя ствола, сколько из этого TCO — сам ствол:

```
Payback = U_combat / (U_combat + U_патронов)
```

`U_патронов` — патроны на `(U_combat / U_point) × 45` HP. Выше % — патроны съедают меньше.

Это не «сложили очки статов». Это «насколько пушка в среднем лучше эталона, с учётом что урон важнее отдачи».

0.05 у темпа отдали урону: выстрел важнее каденса. Сумма живых `w` по-прежнему 1.

Поэтому Shredder не стоит 800, хотя стреляет вдвое чаще. Он кривее и бьёт чуть слабее — произведение это съедает.

Если пушка вдвое лучше **во всех** статах сразу — тогда `2^(0.35+0.15+…+0.05) = 2^1 = 2`, U ≈ 800.

## Пример: Battleaxe

Почти все множители = 1, потому что он и есть эталон. Отдача 0 (эталон 1, pad 1): множитель `(1+1)/(0+1) = 2`, в степени 0.05 → 1.035.

```
U = 400 × 1.035 = 414.1
```

Ноль отдачи чуть поднимает эталон над голой 400.

## Формула множителя

```
factor = (stat + pad) / (ref + pad)     если больше = лучше
factor = (ref + pad) / (stat + pad)     если меньше = лучше
```

`pad` нужен, чтобы ноль не делил на ноль (отдача 0, нокбек 0).

`TypeMul` у ближнего — отдельный множитель **снаружи** (кувалда 1.10). Если засунуть тип в `^w`, `1.10^0.10 ≈ 1.01` и тип бесполезен.

Стат с `live = false` в произведение не входит.

## Дальний бой

Эталон: Battleaxe. `Scale = 400`. `TypeMul` пока везде 1.00.

| id | Что это | Код | Лучше | w | ref | pad |
|---|---|---|---|---:|---:|---:|
| Damage | урон за нажатие | `Damage × NumShots` | больше | 0.35 | 24 | 0 |
| FireRate | скорость выстрела | `1 / Delay` | больше | 0.15 | 5 | 0 |
| Reload | скорость перезарядки | `ReloadSpeed` | больше | 0.10 | 1 | 0 |
| Mag | патроны в обойме | `ClipSize` | больше | 0.10 | 12 | 0 |
| Accuracy | кучность | среднее ConeMin и ConeMax | меньше | 0.10 | 1.625 | 0.25 |
| Recoil | отдача | `Recoil` | меньше | 0.05 | 1 | 1 |
| Kinetic | кинетика | `KnockbackScale` | больше | 0.10 | 1 | 0.2 |
| Weight | вес | `95 / WalkSpeed` | меньше | 0.05 | 1 | 0.1 |

Вес — не `SWEP.Weight`. Это насколько пушка сажает ходьбу.

Relapse-ствол хранит секунды, килограммы и долю потери с дистанцией. В модель они переводятся так (`GM:ExtractRangedUsefulnessValues`):

```
FireRate = 1 / Delay
Reload   = 2 / Reload     -- 2 с → скорость 1.00, как у палки
Mag      = Clip
Kinetic  = 1 − Kinetic    -- остаток урона на дальнем, не доля потери
Weight   = Weight         -- кг; у палки 1.00
```

Accuracy и Recoil идут как есть.

## Новые статы и семейства

Новый стат — только с `w`, `ref`, `better`. Сумма живых `w` = 1, иначе эталон перестаёт быть равным Scale.

Новое семейство (хил, турель) — новая таблица, та же формула.
Цена полки в поинтах в Π не входит. `$/шт` патрона входит как `AmmoMul` снаружи. Окупаемость — отдельный стат.

## Зафиксировано

- `U = Scale × TypeMul × AmmoMul × Π factor^w`, без округления к 10.
- `Scale` дальнего и ближнего: 400.
- Уровень 21–30 (40 U) ≈ 1/10 стартового оружия.
- Показатели дальнего: 0.35 / 0.15 / 0.10 / 0.10 / 0.10 / 0.05 / 0.10 / 0.05.
- `AmmoMul = (0.30 / $) ^ 0.05`. Якорь 9×18. Не в сумме `w`.
- `Payback = U_combat / (U_combat + U_ammo)` на `(U_combat / U_point) × 45` HP.
- Показатели дальнего: 0.35 / 0.15 / 0.10 / 0.10 / 0.10 / 0.05 / 0.10 / 0.05.
- Показатели ближнего (живые): Damage 0.35, SwingDelay 0.15, Stopping 0.10, AttackSpeed 0.10.
- Выносливость, блок, парирование: `live = false`.
- Полки тиров (примерно): T1 355–410, T2 410–460, T3 460–510, T4 510–525, T5 525–545. Потолок PKM ≈ 545.
- Тир шопа ≠ скачок U. Налог цены отдельно.
